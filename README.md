# Inventory Management System

## Description

A Java-based Inventory Management System that allows users to manage products, track stock quantities and calculate inventory information.

## Project Structure

The project consists of three main Java files:

- **Product.java:** Defines individual products, including their ID, name, price and quantity. It also validates product information and prevents invalid values.
- **Inventory.java:** Manages the collection of products. It provides functionality to add, remove, search, sort and update products, as well as generate inventory reports.
- **Main.java:** The entry point of the application. It creates products, adds them to the inventory, calls inventory methods and displays the results.

## Features

- Add products to inventory.
- Remove products using their IDs.
- Search for products by ID or name.
- Sort products by price or name.
- Update product stock quantities.
- Display all products.
- Generate low-stock reports.
- Calculate total stock units.
- Calculate total inventory value.
- Validate product information and handle errors.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Comparator

## How to Run

1. Make sure Java is installed on your computer.
2. Open the project folder in a Java IDE such as VS Code or Eclipse.
3. Make sure all three Java files are in the same project.
4. Open `Main.java`.
5. Run the `main()` method.
